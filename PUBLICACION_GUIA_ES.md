# Guía rápida para publicar el perfil y preparar los pines

## 1. Crear el README del perfil

La conexión GitHub actual permite leer y modificar archivos/repositorios existentes, pero **no dispone de una acción para crear repositorios nuevos**. Por eso falta este paso manual:

1. Inicia sesión como `Wafer2000` en GitHub.
2. Abre https://github.com/new
3. **Repository name:** `Wafer2000` (idéntico al usuario, respetando su nombre).
4. Selecciona **Public**.
5. Activa **Add a README file** y crea el repositorio.
6. Abre `README.md` en la raíz y reemplaza su contenido por el archivo `PROFILE_README.md` de este paquete.
7. Comprueba tu página https://github.com/Wafer2000

Después de crear ese repo, también puedes volver a ChatGPT y pedir: «Actualiza el README de mi nuevo repositorio Wafer2000 con el archivo que preparaste»; si el conector tiene permiso de escritura, puedo actualizarlo desde aquí.

## 3. Crear showcases públicos

El directorio `showcases/` contiene **seis README.md listos** para crear fichas técnicas, sin copiar código comercial. Los nombres recomendados de repositorios son:

1. `commerce-credit-case-study`
2. `musiclinks-licensing-case-study`
3. `playlist-integration-case-study`
4. `digital-marketplace-case-study`
5. `container-operations-pwa-case-study`
6. `ruta-cero-finance-case-study`

No publiques los READMEs de trabajos de terceros hasta confirmar que la descripción, nombre y alcance están autorizados. Antes de fijarlos, complementa cada uno con **capturas anonimizadas y/o código demo reproducible**, para que aporten evidencia de calidad y no sean seis repositorios de solo presentación.
