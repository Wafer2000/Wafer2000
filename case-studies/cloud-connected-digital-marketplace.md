# Cloud-Connected Digital Marketplace

## Overview

A multi-platform marketplace application built around digital products, learning content, seller workflows and cloud integrations.

The project includes a Flutter client and cloud services for authentication, data, payments, messaging, notifications and operational monitoring.

## Engineering focus

- **Client:** Flutter with BLoC and dependency injection.
- **Backend:** Firebase Authentication, Firestore, Storage and Cloud Functions.
- **Payments:** Stripe-based checkout / connected-account workflows.
- **Notifications:** email, push and messaging integrations.
- **Monitoring / protection:** Crashlytics, Analytics and App Check.
- **Delivery:** GitHub Actions and staged branch workflow.

## Engineering workflow

The repository includes separate development, QA, staging and production branches, along with CI checks for:

- Static analysis.
- Automated tests.
- Formatting.
- Dependency maintenance.

## What this project demonstrates

This project demonstrates how a mobile-first product can coordinate with cloud backend capabilities and external services.

It provides evidence of:

- Mobile architecture.
- Cloud Functions.
- Authentication and authorization.
- Payment integrations.
- Notification systems.
- CI/CD practices.
- Production-oriented Firebase usage.
